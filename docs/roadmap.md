# Roadmap

Direction, not dates. This is early — the point of the roadmap is to make the order of operations clear, not to promise a schedule.

## Phase 0 — Foundation (now)
- [x] Repository, principles, and structure
- [ ] Core engine skeleton: task planning loop, tool interface, context/memory
- [ ] Authorization & audit gate as a first-class, enforced component
- [ ] One model backend wired end to end

## Phase 1 — Teach
- [ ] Lab format and a first sandboxed lab
- [ ] Adaptive tutor over curriculum data
- [ ] Learner progress tracking (private by default)

## Phase 2 — Guide
- [ ] Methodology knowledge base
- [ ] Step-suggestion reasoning for authorized engagements
- [ ] Scope enforcement and gap-flagging

## Phase 3 — Execute
- [ ] Safe automation: recon, parsing, triage
- [ ] Report drafting from engagement data
- [ ] Agent capability plugins

## Phase 4 — Platform
- [ ] Clean install / self-host path
- [ ] Open-core tier boundaries documented
- [ ] First tagged release

---

Priorities shift with what gets built and what people need. If you want to push one of these forward, see [CONTRIBUTING.md](../CONTRIBUTING.md).
